# Planify (React Edition)

A modern, fast, and feature-rich task manager and project planner built with React 19, TypeScript, and Tailwind CSS.

## ✨ Features

- **🚀 Task & Project Management**: Organize tasks into projects, sections, and Kanban boards.
- **🏷️ Smart Filters & Labels**: Quick views for Inbox, Today, Tomorrow, Scheduled, Pinboard, Completed, and Custom Tag Labels.
- **☁️ Nextcloud Tasks & Deck Sync**: Optional synchronization with Nextcloud Deck boards and CalDAV Tasks.
- **⚡ Natural Language Quick Add**: Type `#project`, `@label`, `!p1`, `today`, or `tomorrow` to automatically organize tasks on the fly.
- **📊 Productivity Analytics**: Track task completion heatmaps, daily goal progress, and activity streaks.
- **🌙 Multiple Themes**: Crisp Light, Dark, and Dark Blue appearance modes.
- **💾 Offline First**: Local persistence with JSON backup export and import support.

## 🛠 Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Lucide React
- **Persistence**: LocalStorage with Nextcloud Deck / CalDAV integration

## 🏃 Getting Started

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
